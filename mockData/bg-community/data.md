Fill in one block per organization / person / business below.
I'll batch-convert these into `bg-community-in-canada.json` (headings + infoCards + collections).

## How to fill an entry

- **Required:** `Name (EN)`, `Tags`, `City`.
- **Tags:** one or more category slugs from the table below, comma-separated (e.g. `folk-club, association`). These are the filterable category tags.
- **Bilingual fields:** add `(BG)` if you have a Bulgarian version; leave blank and I'll reuse the EN value or transliterate.
- **Leave a field blank** to omit it. Delete the whole `Notes` line if unused.
- Copy the `--- ENTRY ---` block as many times as you need.

## Reference — valid Tags (group → category)

| Group | Categories |
|-------|-----------|
| Community | `association`, `cultural-center`, `school`, `folk-club` |
| Faith | `church` |
| Media | `newspaper`, `radio` |
| Services | `plumber`, `electrician`, `cleaning` |
| Professional | `lawyer`, `accountant`, `photographer`, `realtor`, `notary`, `doctor`, `business` |
